# 3D Assets Pro - Landing Page

A modern landing page for a 3D assets startup featuring a carousel of 3D models and an email subscription form.

## Features

- Responsive design that works on all devices
- Interactive 3D model carousel
- Detailed 3D model viewer
- Email subscription form
- Smooth animations and transitions

## Technologies Used

- HTML5, CSS3, JavaScript
- [Three.js](https://threejs.org/) for 3D rendering
- [Bootstrap 5](https://getbootstrap.com/) for responsive layout
- [Font Awesome](https://fontawesome.com/) for icons

## Getting Started

1. Clone the repository
2. Open `index.html` in a modern web browser
3. No build process or dependencies required - it works right out of the box!

## Usage

- Click on any 3D model in the carousel to view it in the fullscreen viewer
- Use your mouse to rotate, zoom, and pan the 3D model
- Enter your email in the subscription form to receive updates

## Customization

To add your own 3D models:
1. Replace the placeholder geometries in `script.js` with your own 3D models
2. Update the model information in the HTML
3. Customize colors and styles in `styles.css`
